# Lab 03 – Homework Skeleton

This repository is a **starter structure only**. It intentionally does not contain completed homework features or business logic.

## Working rules

1. Work on one homework at a time.
2. Read the matching requirement before implementing anything.
3. Reuse Lab 02 code only after reviewing it and deciding what must change.
4. Implement one small requirement at a time: understand → code → test → review.
5. Record reproducible bugs in `BUG_LOG.md` and AI-related failures in `HW3_PUBG_Arena/AI_FAILURE_AUDIT.md`.
6. Commit after each meaningful, tested milestone.

## Project layout

- `HW1_DrumKit/` – Production Studio Drum Kit (React 19 + TypeScript + Vite scaffold)
- `HW2_Piano/` – 88-Key Polyphonic Piano (React 19 + TypeScript + Vite scaffold)
- `HW3_PUBG_Arena/` – PUBG Vietnam Airdrop Arena (React 19 + TypeScript + Vite scaffold)
- `Bonus_Situationship_FSM/` – optional bonus exercise scaffold

Each homework is an independent Vite app. Open the specific homework folder in a terminal before running npm commands.

## Run a homework

```bash
cd HW1_DrumKit
npm install
npm run dev
```

Use the same commands inside `HW2_Piano` or `HW3_PUBG_Arena` when we begin those tasks.

## Important

- No homework functionality has been implemented in this skeleton.
- `App.tsx` files are intentionally minimal placeholders.
- Placeholder modules contain TODO comments only.
- No `package-lock.json` is included; `npm install` will generate one locally.
- Do not copy all of Lab 02 wholesale. See `REUSE_MAP.md` and bring over only the modules we review together.
